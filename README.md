# 熊谷热 · 狼夜（网页版原型）

KUMAGAYA HOT MOTO CLUB 狼人杀多人网页原型，支持6–12人、6位房间号、随机身份、线下主持、昼夜阶段、匿名投票、出局与胜利判定。

## 运行

安装 Node.js 20+，进入目录执行：

```bash
npm install
npm start
```

浏览器打开 http://localhost:3000 。要让其他手机加入，需要把此服务部署至有 HTTPS 的公网 Node.js 主机，不能只把 `index.html` 上传到静态空间。

## 放置品牌 Logo

将**已授权使用的熊谷热俱乐部高清 Logo**命名为 `logo.png`，放入 `public/`。没有 Logo 时显示熊 emoji 占位符。

## 当前范围与限制

- 本版本是**线下聚会主持版**，不是完整自动法官；夜间狼人、女巫、预言家等技能由真人主持，房主在系统里标记死者。不要将此版本描述为完整自动判官版。
- 断线、刷新会改变玩家连接身份；目前没有账号、持久化、断线重连或防作弊机制。
- 房间数据仅在服务内存中；服务器重启则房间失效。
- 目前没有实时语音、微信登录、后台数据库、监管/内容安全功能。
- 公网上线前，需要完善防刷、速率限制、会话恢复、房间过期清理、访问审计、HTTPS 与压力测试。
- 这是一份可运行的 **MVP 起点**，需要进一步测试和完善游戏规则后再公开运营。
